# 🌿 Sakhinool (സഖിനൂൽ)
### *“Woven in Tradition, Styled for You”*

> **Sakhinool** (roughly translated to *“friend as wool or thread”*) is an interactive digital boutique and product showcase crafted to deliver authentic, handpicked sarees across Kerala. 

---

## 🎨 Brand Aesthetic & Palette
- **Primary Colors**: Deep Heritage Forest Green (`#051910`, `#0a261a`, `#0f3525`)
- **Accents**: Radiant 24K Gold Zari (`#d4af37`, `#e5c158`, `#fff2c6`) & Kasavu Ivory (`#faf7f0`)
- **Typography**: Royal Classic Serif (*Cinzel*, *Cormorant Garamond*) & Modern Sans (*Plus Jakarta Sans*)

---

## ✨ Features
- **Authentic Monogram & Wordmark**: Vector recreation of the brand packaging logo (female silhouette in traditional Kerala kasavu necklace flowing into a calligraphic "S" with needle and spun thread, plus stylized "oo" loop).
- **Interactive Saree Matcher**: A 3-step interactive stylist assistant that filters weaves by Occasion (*Temple & Onam/Vishu, Wedding & Muhurtham, Evening Reception*), Fabric (*Kasavu, Pure Silk, Golden Tissue, Organza*), and Budget.
- **Curated Handloom Catalog**: 
  - *The Royal Mayura Forest Silk* (Signature Forest Emerald & 24K Gold Zari)
  - *Aswathy Kasavu Handloom* (Balaramapuram Cotton-Silk with Temple Kara)
  - *Vishu Kani Shimmer Golden Tissue* (Liquid Gold with Emerald Border)
  - *Nila Royal Peacock Bridal Kanchipuram*
  - *Kunkumam Crimson Banarasi Katan*
  - *Gulabi Scalloped Organza Romance*
  - *Indraneelam Midnight Blue Soft Silk*
  - *Manjal Haldi Auspicious Silk*
- **Saree Detail Modal**: Specifications (Weave, Zari, Length, Blouse piece, Care instructions) and a Kerala Delivery Estimator across all 14 districts.
- **Inquiry Bag & WhatsApp Order Generator**: Bridge to gradual e-commerce. Customers assemble their bag, select their Kerala shipping district, and generate an itemized WhatsApp order message sent directly to **+91 7306045546**.
- **Signature Packaging Spotlight**: Showcases the brand's emerald green & gold unboxing experience with wax seals and personalized gift cards.
- **Customer Voices & FAQ**: Testimonials from patrons across Kochi, Trivandrum, Kozhikode, and Thrissur.
- **Socials Integration**: Connected directly to [@sakhinool on Instagram](https://www.instagram.com/sakhinool?stkn=MTRwMjUxZDF1eGUzYQ==) and WhatsApp (+91 7306045546).

---

## 🛠️ Tech Stack
- **Framework**: Next.js 16 (App Router) + React 19 + TypeScript
- **Styling**: Vanilla CSS Design System with CSS Custom Properties
- **Icons**: Lucide React + Custom SVG Brand Icons

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev -- -p 3005
```
Open [http://localhost:3005](http://localhost:3005) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start -- -p 3005
```
